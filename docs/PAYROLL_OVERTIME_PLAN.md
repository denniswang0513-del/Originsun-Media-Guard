## 0. 一句話

先把「每個人一個月領多少、扣多少、公司另外負擔多少」放進系統（**薪資單**），再做**加班申請**：核准後平日 1:1、假日 1:2 進補休時數帳，或換成加班費直接長在下個月的薪資單上。錢的流向不變——薪資單確認後自動變成請款單，走現有的應付／匯款流程，公司帳自動有「薪資」那一列。

## 2. 目標模型（三張新表 ＋ 一張改表）

### 2.1 薪資主檔 `staff_pay_profiles`（一人一段期間一列，改薪水就新增一列）

| 欄 | 說明 | 例 |
|---|---|---|
| staff_id | 員工 | |
| effective_from | 從哪個月起適用 | 2026-01 |
| pay_type | 月薪／時薪／日薪 | 月薪 |
| base_amount | 底薪（月薪制＝每月；時薪制＝每小時） | 40,000 |
| meal_allowance | 伙食費（免稅上限 3,000） | 3,000 |
| labor_grade | 勞保投保薪資 | 43,900 |
| health_grade | 健保投保金額 | 43,900 |
| pension_self_rate | 勞退自提 %（0–6） | 0 |
| dependents | 健保眷屬加保人數 | 0 |
| payroll_entity | 誰付：公司 ／ 代發（股東自己的人） | 公司 |
| pay_day | 每月幾號發 | 5 |
| note | | |

時薪換算：月薪制的「每小時工資」＝ base_amount ÷ 240（勞動部算法，30 天 × 8 小時）。40,000 ÷ 240 ＝ 166.7 元。

### 2.2 費率表 `payroll_rate_tables`（一年一份，系統先帶 2026 版）

勞保級距表、健保級距表、勞保費率（含就業保險）、健保費率、勞退雇主 6%、健保平均眷口數、二代健保補充保費門檻。**每年 1 月更新一次**——貼官方表進去就好，不用改程式。每個人的自負額／雇主負擔都從這裡查，不再手算。

### 2.3 薪資單 `payroll_runs`（一個月一張）＋ `payroll_lines`（一人一列）

```
payroll_runs:  id, entity(parent), month(2026-09), status(草稿→已確認→已發薪), confirmed_by/at, note
payroll_lines: id, run_id, staff_id, staff_name(快照), pay_type,
               work_hours(時薪制用), base_pay, meal_allowance,
               overtime_pay, bonus, leave_deduction(事假／病假半薪),
               labor_self, health_self, pension_self, other_deduction,
               gross(應發), net(實發),
               labor_employer, health_employer, pension_employer(雇主負擔，不進實發),
               payroll_entity(公司／代發), bank_name, bank_account(快照),
               payment_request_id(確認後產生的請款單), paid_date, note
```

規則：
- 「產生本月薪資單」＝把主檔有效的人全部帶進來；時薪制的人**時數手填**（owner 2026-09-17：「時數手填」），旁邊只顯示工時表該月合計當參考，不自動帶。
- 加班費、請假扣薪、獎金三欄由系統帶入（見 §3），都可以手改，改了會標「手改」。
- **狀態「已確認」時**：每列自動長一張請款單（category＝薪資、payee＝員工、planned_month＝該月），走現有應付／匯款通知／銀行對帳。`payroll_entity＝代發` 的列 category 改「代發薪資」，維持過帳不算費用。
- 三表把 6100／6110／6120 抽成「人事費用」一組，`monthly_fixed_costs` 改成「上個月薪資單雇主總成本＋房租」自動帶（手打值仍可覆蓋）。
- 匯出：印領清冊（Excel）＋ 每人薪資條（PDF），給會計用。

### 2.4 加班申請 `hr_overtime_requests`

| 欄 | 說明 |

## 3. 算法（純函式，放 `core/payroll_logic.py`，先寫測試）

### 3.1 每月薪資單一列

```
應發 gross = base_pay + meal_allowance + overtime_pay + bonus − leave_deduction
實發 net   = gross − labor_self − health_self − pension_self − other_deduction
雇主總成本 = gross + labor_employer + health_employer + pension_employer
```
時薪制：`base_pay = 時薪 × 該月時數`。例：220 × 88 h ＝ 19,360；勞保自負 528、健保自負 426 → 實發 18,406。

請假扣薪（先做最常見兩種）：事假整天扣 `月薪 ÷ 30`；病假半薪扣一半；兩者時數從已核准的請假單抓。

### 3.2 加班費（owner 2026-09-17：「加班費照公司規定」）

公司規定跟補休同一把尺：**工作日 ×1、假日（休息日／國定假日／例假／颱風假有上班）×2**，基數＝每小時工資（月薪 ÷ 240，或時薪）。倍率放堡壘式設定 `overtime.pay_multiplier = {"workday": 1, "holiday": 2}`，管理員可改，不寫死。

例：月薪 40,000（每小時 166.7）
- 工作日加班 2 h → 166.7 × 1 × 2 ＝ **333 元**；選補休 → **2 h**
- 週六加班 8 h → 166.7 × 2 × 8 ＝ **2,667 元**；選補休 → **16 h**

⚠️ 備註（不擋、只記）：勞基法 §24 的最低標準是工作日前 2 小時 ×1.34、之後 ×1.67；公司規定工作日 ×1 低於這條，假日 ×2 高於這條。系統照公司規定算，設定頁旁邊放一行「法定最低 1.34／1.67」提醒。

守衛：每月加班（含補休換的）超過 46 小時標黃、超過 54 小時擋下（勞基法 §32）；同一天同一人重疊時段擋下。

### 3.3 一月結算（補休到期）

1 月 1 日：去年 12/31 到期還沒用的補休 → 管理端一鍵：展延到今年 12/31，或折薪（按原加班日種類的加班費倍率算，掛進 1 月薪資單）。同一顆按鈕分人選。

## 8. 不動的地方／地雷

- 薪資、獎金、勞健保不能掛專案（`core/project_link.py` 已擋 409），薪資單產生的請款單也不掛。
- `PayeeResolver`：薪資單長出的請款單 payee 一律用員工正式姓名＋身分證，不走別名比對。
- 兩本帳：薪資單只有母公司（entity＝parent），私帳那邊 `公司_薪水/<人名>` 的樹維持是「王士源自己帳的分類」不動。
- 工時表不做加班推論（`docs/TIMESHEET_SELF_ENTRY_PLAN.md` 第 83 行）——加班一定要員工自己報，工時表只拿來「幫他預填起訖」。
- `hr_leave.js` 只能用 `//` 註解；通知文字無 emoji；員工自助端點不收客戶端算好的時數。
